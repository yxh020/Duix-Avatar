   AI数字人 · Docker 版客户端（绿色版）
═══════════════════════════════════════════════

【一句话上手】

  把这整个文件夹拷到本机硬盘（D:\ 或桌面），
  双击 "AIShuZiRen.exe" 即可。
  （图标是有 logo 那个，不要双击别的）

═══════════════════════════════════════════════
   连本机 / 连别的机器
═══════════════════════════════════════════════

  默认连本机 127.0.0.1（如果本机有 Docker 跑着容器就开箱即用）。

  如果本机没装 Docker，要连同局域网另一台装了 Docker 的机器：
     应用左下角点 "服务器" 图标
     → IP 改成那台机器的局域网地址（例如 192.168.3.105）
     → 点 "测试连接"，两个圆点都变绿就行
     → 点 "保存"，立即生效

  保存的设置存在 %APPDATA%\AI数字人\server-config.json，
  下次开机自动用，不会丢。要回默认值点设置页里 "恢复默认"。

═══════════════════════════════════════════════
   连不上排查
═══════════════════════════════════════════════

  在设置页 "测试连接" 看结果：

  - 两个都绿（通 ✓）       → 服务正常
  - 端口通 / 服务无响应    → 容器还在启动，等 30 秒再测
  - 不通 ✗                → 排查这三件事：
       a) 本机 ping 那台机器的 IP 通不通
       b) 那台机器的 Docker 容器是否在跑
       c) 那台机器的防火墙是否放行 8383 / 18180 端口
          （右键 服务端-开放共享.bat → 以管理员身份运行）
