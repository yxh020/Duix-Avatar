        AI数字人 · 整合包 · 安装说明
═══════════════════════════════════════════════

最短流程（按顺序做，全程双击）：

  1. 把整个文件夹复制到电脑硬盘（建议 D:\ 或某个空间≥80GB的盘）。
     不要直接在 U 盘里运行。

  2. 装显卡驱动（如果没装过）：
       NVIDIA 官网下你显卡型号的驱动 → 安装 → 重启
     （本包不带驱动，需要按你显卡型号自己下）

  3. 装 WSL（如果没装过）：
       installers\wsl-offline-installer-20260507\安装WSL.bat
       右键 → 以管理员身份运行 → 装完重启

  4. 装 Docker Desktop（如果没装过）：
       installers\DockerDesktopInstaller.exe
       双击安装 → 默认选项 → 装完重启 → 开机后打开 Docker Desktop
       等任务栏 Docker 图标变绿（约 30-60 秒）

  5. 装 AI数字人 应用：
       installers\AI数字人-1.0.7-setup.exe
       双击安装，桌面会出快捷方式

  6. 启动服务（此后每天用就是这一步）：
       双击根目录的 "开始使用.bat"
       - 第一次运行约 3-5 分钟（要导入 5GB 镜像）
       - 之后运行约 10 秒

  7. 想停服务（只在不用电脑时）：
       双击根目录的 "停止服务.bat"

═══════════════════════════════════════════════
        故障处理
═══════════════════════════════════════════════

任何启动失败 / 出片异常 / 红色错误：

  双击 "环境诊断.bat"
  按菜单数字处理：
     1. 综合诊断（先做这个，截图发技术）
     2. 重启容器
     3. 停止容器
     4. 重新导入镜像（镜像损坏时用）
     5. 查看容器日志
     6. 启动应用窗口

═══════════════════════════════════════════════
        硬件要求
═══════════════════════════════════════════════

  - Windows 10/11 64 位
  - NVIDIA 显卡（RTX 3060 及以上推荐，4060 Ti 测试过）
  - 内存 16 GB 起步，推荐 32 GB
  - 磁盘 ≥ 80 GB 空闲（推荐 D: 盘）
